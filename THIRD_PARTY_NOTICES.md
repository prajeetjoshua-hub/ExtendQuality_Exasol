# Third-party materials and provenance

This repository imports a snapshot extending the pre-existing ExtendQuality prototype. Its historical authorship remains in the original repository and a local development backup; the import author is not represented as the sole author of inherited work. No new blanket license is asserted over inherited code, photographs, models or prior-event materials.

Dependencies retain their own licenses. The software uses React, Next.js/vinext, Vite, FastAPI, OpenCV, NumPy, Pillow, PyExasol and optional Ultralytics/PyTorch. Review their distributed license files before redistribution or commercial use. In particular, adding an Ultralytics-derived model requires checking the applicable upstream model/software terms.

The deterministic synthetic records and SVG repository diagrams were created for this project. They are illustrative, not factory data. Private credentials, captured photographs, runtime databases and model weights are excluded from the working-tree publication.

Legacy event documents remain historical materials and do not establish current Exasol submission readiness or current product claims. AI development assistance is disclosed; user ownership metadata does not replace genuine Git authorship.

Public visibility is for review and evaluation. A project-wide redistribution license has not yet been selected by the rights holders.
